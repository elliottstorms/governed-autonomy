# The starting path

The [README](README.md)'s "If you are starting this week" section as literal checkboxes. Check them off in your own fork.

## Day one

- [ ] Install Claude Code: `npm install -g @anthropic-ai/claude-code`
- [ ] Copy [templates/operator-manual.md](templates/operator-manual.md) into `~/.claude/CLAUDE.md`
- [ ] Fill in Tier 1 (safety) honestly; delete what you are not ready to mean
- [ ] Start a session and ask Claude what rules it sees

## Week one

- [ ] Create a memory directory and index file
- [ ] Run your most annoying recurring workflow with the AI, by hand
- [ ] Run it by hand a second time
- [ ] Write down what worked, with the why attached

## Week two

- [ ] Turn that workflow into your first skill at `~/.claude/skills/<name>/SKILL.md`
- [ ] Install your first hook from [examples/first-hook.md](examples/first-hook.md)
- [ ] Make the hook fail on purpose and watch it catch

## Month one

- [ ] Stand up an append-only ledger with one controlled write path
- [ ] Split your task board: actionable-now separate from dated work
- [ ] Set up a daily sync that closes items only on live evidence
- [ ] Add secret scanning before your first push to any repo

## After that

- [ ] Split AI roles into charters; make checking roles read-only
- [ ] Add the learning loop: capture corrections, fold them back with evidence
- [ ] Mirror everything durable to a private repo behind a tripwire
- [ ] Run a restore drill and diff the clone against the live sources
- [ ] Build the public pipeline with pre-publish gates that fail closed

## Last, on purpose

- [ ] Grant your first standing autonomy: in writing, scoped, with an expiry date and a one-word kill switch
